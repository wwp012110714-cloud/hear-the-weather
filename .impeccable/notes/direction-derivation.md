# 视觉方向推导（new-work-world 步骤 1–3）

## 1. 机制 / 场景 / 文化归属 / 首屏要证明什么
- 机制：把某城“此刻的天气”翻译成一份可播放的人声歌单与环境声 —— 天气不是读的，是听的。
- 受众场景：国内高校老师与同学，在电脑桌面浏览器打开课程网站，几分钟内评判一份 Vue 创意作业。
- 文化归属：当代中国大陆；中文天气与流行音乐的共同记忆。
- 首屏必须证明：天气 → 音乐 的联动一眼可懂，并诱导切换城市去“听”另一种天气。

## 车辙（排除在候选之外）
- 品类默认：深色/渐变天空 + 毛玻璃卡片 + 超大温度 + 发光图标的天气 App 仪表盘；Spotify 式深色音乐播放器。
- 可预期的反面：白底极简瑞士风天气卡片。
- 名字的字面读法（耳机 + 声波 + 云朵）：最多占一个候选，这里不占。

## 2. 七个来自受众文化世界的候选（按共鸣排序，跨 ≥3 个材质家族）
1. 【广播电视】CCTV《新闻联播》后的《天气预报》—— 全国人每晚 19:30 熟悉的城市字幕条 + 配乐《渔舟唱晚》：天气与音乐在中国本来就绑在一起。
   外观：深蓝底、白/黄字幕条、粗黑体城市名与温度、栏目化包装。
2. 【纸张印刷】老黄历 / 手撕日历本 —— 每天一页：大号日期、农历、节气、宜忌。
   外观：米白薄纸、朱红与墨黑、宋体大字、竖排小字、印章。“宜：听《晴天》”。
3. 【物件塑料】90 年代磁带与卡带内页（J-card）—— 每座城市此刻的天气是一盘自录合辑。
   外观：卡带侧标彩条、打字机/手写曲目单、塑料壳反光。
4. 【公共标识】火车站车次大屏（红色点阵 LED / 翻牌）—— 城市像车次一样排列，切城即“出发”。
   外观：黑底红/琥珀点阵字、等宽列、滚动更新。
5. 【家用物件】老式半导体收音机调频刻度盘（熊猫牌）—— 拧旋钮扫过城市，像扫过电台。
   外观：木纹/米色面板、刻度窗、红色指针。
6. 【数据图形】中央气象台地面天气图（等压线 + 站点填图符号）—— 专业气象记号的图形语言。
   外观：白纸、蓝红等压线、站点符号、细线标注。
7. 【绘画书写】宋人诗词与水墨 —— “夜雨寄北”式雨雪诗意。
   外观：宣纸、水墨晕染、行楷。（风险：最易落入“中国风”套路）

## 3. 完整方向（世界 × 首屏体验）
- A 天气预报节目：首屏是“今晚的天气预报”栏目包装，城市字幕条依次滑入，选中城市即在下三分之一字幕里“正在播放：赵雷《成都》”。
  风险：若使用中国地图，地图必须完整准确（含全部领土），否则有合规风险 → 用字幕条列表而非地图。
- B 黄历撕页：首屏是今天这一页——城市 + 巨大日期/温度 + 农历节气 + “宜听 / 忌” 歌单；切城市像撕下一页。
- C 卡带合辑：每个城市天气一盘卡带，内页即歌单。
- D 车次大屏：城市天气以车次表形式排布，点阵翻牌更新。
