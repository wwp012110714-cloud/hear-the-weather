# 听见天气（Hear the Weather）

> 一个基于 **Vue 3** 构建的城市实时气象感知与氛围音乐漫游单页应用（SPA）——**让你不仅能看见各地阴晴冷暖，还能听见此刻天气里的旋律与风声。**

---

## 一、我的创意，以及为什么觉得它有意思、有意义

### 1. 创意灵感
日常使用的天气网页往往只停留在冷冰冰的数字罗列（几度、湿度多少、下不下雨），看完即关；而音乐播放器里的推荐歌单又很少真正感知我们窗外此刻的阴晴昼夜。

**《听见天气》** 想把这两件充满生活感的事自然地连接在一起：
- 当你点进**漠河或哈尔滨**的凛冽冬日，界面化作松蓝雾凇，唱针落下是温暖治愈的冬日钢琴，耳畔还能叠加上微微噼啪的围炉暖火声；
- 当你点进**三亚或厦门**的晴热海滨，天色铺开暖金微光，电台自动调频至海风汽水感的轻快流行曲；
- 当某座江南小城细雨淅沥，青黛色的雨丝滑过屏幕，细雨敲窗的白噪音与温柔民谣缓缓响起。

用户既可以把它当作一个**查询全国乃至全球城市实时天气、空气质量与未来 7 天趋势的实用工具**，也可以把它当作一座**跨越山海的“声音旅行电台”**。

### 2. 为什么有意思、有意义
1. **打破单一数据的枯燥感，赋予气象数据情绪温度**：通过自研的「气象声学智能映射引擎」，将真实的 WMO 天气现象码、实时气温、昼夜节律、风速与城市人文气质，实时转化为贴合心境的音乐频道与推荐判词，每次切换城市都是一场未知的视听偶遇。
2. **兼顾实用价值与情绪陪伴**：无论是在宿舍自习想找契合雨夜的背景白噪音，还是出行前查看目的地未来一周气温与空气质量，都能在一个清爽的单页应用里完成。
3. **封存“晴雨记忆”的情感连接**：收藏一首歌时，应用不仅保存歌曲本身，还会自动盖上收藏那一刻的**「城市 + 实时温度与天气」印章**（例如：`收藏于 大理 · 18°C 晴`），让歌单成为一份有时间与空间温度的声音手账。

## 二、页面的功能描述

1. **神州城市实时漫游栏 & 全局中文搜索**
   - 顶栏内置哈尔滨、漠河、北京、成都、杭州、大理、拉萨、厦门、重庆、三亚等横跨不同气候带的漫游入口，页面加载时通过批量接口一次性获取各城实时温度与天气图标，直观展现南北温差与晴雨对比。
   - 支持**中文实时搜索任意城市**（带防抖联想、行政区划与经纬度展示），也支持**「随机漫游」**一键飞往国内随机目的地，以及**「定位身边」**获取当前所在位置的实时天气与专属音乐。
   - 顶栏集成中国传统**今日农历干支印章**，增添东方时令韵味。

2. **沉浸式实时气象与空气质量看板（左栏）**
   - **实时核心指标**：动态展示所选城市的当前气温、体感温度、昼夜状态、风速风向、相对湿度、天空云量、气压、降水量、紫外线指数及防晒建议。
   - **空气质量监测**：实时拉取当地 AQI 指数与 PM2.5 浓度，自动换算优/良/轻度等级徽章。
   - **昼夜节律进度条**：根据当地真实日出、日落时间动态计算太阳运行进度。
   - **24 小时逐时 SVG 温度折线图 & 未来 7 天趋势条**：支持自由切换查看；更特别的是，在「未来 7 天趋势」中**点击任意一天即可穿越试听该日预报天气对应的音乐声景**，并可随时一键返回此刻实时状态。

3. **气象智能推歌黑胶电台（右栏）**
   - **智能气象调频解析**：清晰展示当前推导逻辑（基于城市、天气现象、温度、昼夜、风速匹配的声景频道名称与检索标签）。
   - **拟物黑胶唱机交互**：播放时黑胶唱片匀速旋转、拟物唱臂平滑落针、均衡器声波实时跳动；支持播放/暂停、上一首/下一首、自动连播、进度条拖拽跳转、音量调节。
   - **多维曲风切换与自由点歌**：除默认「随天气智能调频」外，还可在当前天气基调下切换「华语流行 / 城市民谣 / 治愈纯音 / 微醺爵士」、点击「换一批曲目」，或直接在电台内输入歌手/曲名自由点歌。

4. **浏览器原生实时自然环境白噪音混音器**
   - 基于 Web Audio API 实时程序化合成**细雨敲窗、微风拂叶、冬夜围炉、晴空风铃**四路自然声景，默认随所选城市的真实降雨量、风速和温度自动配比，支持手动精细滑块调音并与黑胶音乐叠加播放。

5. **动态天象背景画布 & 晴雨记忆收藏夹**
   - 全屏背景色板与 Canvas 粒子系统随所选城市的实时天气平滑过渡（晴昼暖光、雨天雨丝、雪天飞雪、雷暴微闪、夜晚繁星），支持随时开关动效。
   - 点击红心即可将心仪歌曲连同当时的城市实时天气一起封存至本地 `localStorage`「晴雨记忆收藏夹」，刷新页面不丢失，随时回放。

6. **完善的加载中与异常处理状态**
   - 气象面板、搜索下拉框与音乐列表均设计了**骨架屏闪烁动画（Loading）**与**加载失败友好提示 + 一键重试按钮（Error Retry）**，确保弱网或接口波动时依然体验完整。

## 三、使用的公共 API 说明

本项目所有数据均**实时动态获取**，未在代码中写死天气或歌单数据。所用接口全部收录于作业指定的 [GitHub Public APIs](https://github.com/public-apis/public-apis) 官方仓库，免密钥（`Auth: No`）、支持 `HTTPS` 与浏览器跨域（`CORS: *`），国内网络直连稳定快速：

| 序号 | API 名称 | Public APIs 所属分类 | 用途说明 |
| :--- | :--- | :--- | :--- |
| 1 | **Open-Meteo Weather, Geocoding & Air Quality API** | `Weather` / `Environment` | 中文城市经纬度检索、PM2.5 / AQI 空气质量指数、实时气象与多日预报 |
| 2 | **Meteorologisk Institutt (MET Norway) API** | `Weather` | 全球高精度气象实时观测与未来 7 天预报（与 Open-Meteo 构成双源毫秒级竞速容灾） |
| 3 | **Apple iTunes Search API** | `Music` | 根据气象智能映射词组实时检索华语流行与网络热歌、获取高清专辑黑胶封面与正版人声试听流 |
| 4 | **Radio Browser API** | `Music` | 实时拉取国内在线 FM 音乐广播电台列表（接入 `.cn` 纯 MP3 24 小时全长音乐实况连播） |
| 5 | **Hong Kong Observatory Open Data API** | `Weather` | 实时查询当日中国传统农历年份、生肖与农历月日 |
| 6 | **Deezer API** | `Music` | 备用人声曲库：iTunes 在当前网络不可达时自动接管（JSONP + 标准 MP3 试听流） |

> **音乐链路三级容灾**：iTunes（CORS fetch 与 JSONP 双通道竞速）→ Deezer 备用曲库 → Radio Browser 国内 FM 音乐台 MP3 直播。任何一级可用时都能出声，并在界面上提示当前使用的来源。

## 四、本地开发与课程服务器部署指南

### 本地运行
```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 构建生产环境静态文件（已配置相对路径 base: './'，支持任意子目录或根目录部署）
npm run build
```

构建完成后，将生成的 `dist/` 目录内全部静态文件上传至课程网站服务器（`http://106.13.165.42`）对应目录即可直接通过公网浏览器访问。
