# 听见天气（Hear the Weather）

> **在线访问：<https://wwp012110714-cloud.github.io/hear-the-weather/>**（GitHub Pages，推送到 main 后由 Actions 自动构建发布）

> 一个基于 **Vue 3** 构建的城市实时气象感知与氛围音乐漫游单页应用（SPA）——**让你不仅能看见各地阴晴冷暖，还能听见此刻天气里的旋律与风声。**

---

## 一、我的创意，以及为什么觉得它有意思、有意义

### 1. 创意灵感
日常使用的天气网页往往只停留在冷冰冰的数字罗列（几度、湿度多少、下不下雨），看完即关；而音乐播放器里的推荐歌单又很少真正感知我们窗外此刻的阴晴昼夜。

**《听见天气》** 想把这两件充满生活感的事自然地连接在一起：
- 当你点进**漠河或哈尔滨**的凛冽冬日，界面化作松蓝雾凇，唱针落下是温暖治愈的冬日钢琴，耳畔还能叠加上微微噼啪的围炉暖火声；
- 当你点进**三亚或厦门**的晴热海滨，天色铺开暖金微光，电台自动调频至海风汽水感的轻快流行曲；
- 当某座江南小城细雨淅沥，青黛色的雨丝滑过屏幕，细雨敲窗的白噪音与温柔民谣缓缓响起。

用户既可以把它当作一个**查询全国乃至全球城市实时天气、空气质量与未来 7 天趋势的实用工具**，也可以把它当作一座**跨越山海的“声音旅行电台”**。

### 2. 为什么有意思、有意义
1. **打破单一数据的枯燥感，赋予气象数据情绪温度**：通过自研的「气象声学智能映射引擎」，将真实的 WMO 天气现象码、实时气温、昼夜节律、风速与城市人文气质，实时转化为贴合心境的音乐频道与推荐判词，每次切换城市都是一场未知的视听偶遇。
2. **兼顾实用价值与情绪陪伴**：无论是在宿舍自习想找契合雨夜的背景白噪音，还是出行前查看目的地未来一周气温与空气质量，都能在一个清爽的单页应用里完成。
3. **封存“晴雨记忆”的情感连接**：收藏一首歌时，应用不仅保存歌曲本身，还会自动盖上收藏那一刻的**「城市 + 实时温度与天气」印章**（例如：`收藏于 大理 · 18°C 晴`），让歌单成为一份有时间与空间温度的声音手账。

## 二、页面的功能描述

整页被设计成一张**气象站「地面填图纸」**：气象员在纸上逐站填写读数、手绘等温线，我们把同样的版式用在了推歌上。图面有三种画法，**每 9 秒自动轮换一次**；只要有任何点击或键盘操作，轮换就停在当前画法，顶栏的「轮换」按钮可以重新打开。

1. **三种图式，自动轮换**
   - **① 填图（全国站点图）**：哈尔滨、漠河、北京、成都、杭州、大理、拉萨、厦门、重庆、三亚 10 个测站按真实经纬度投影到纸面。每站按填图惯例画**站圈（涂黑比例 = 云量）+ 风羽（指向来风方向）+ 气温读数**；用各站实况气温做反距离加权插值，**手绘风格等温线**每 4°C 一条。点任意站点即切换城市，被选站点用红圈标出，一条红色引线连到播放器批注框。
   - **② 站点（巨型站点符号）**：把当前城市的站点符号放大成整幅图的主角，四周标注气温、气压、湿度、云量、体感和风级。右侧是测站索引表和歌曲记录。
   - **③ 自记（温度自记纸）**：仿照气象站自记温度计的弧形坐标纸，画出未来 24 小时气温曲线。**推荐的歌曲按顺序写在曲线上**，像值班员在自记纸上写的附注。
   - 三种图式底部都有 24 小时气温小曲线；把 URL 加上 `?view=map|station|trace` 可以直接打开某一种图式。

2. **城市检索与漫游**
   - 中文实时搜索任意城市（防抖联想，显示行政区和经纬度），另有「定位」和「随机一站」。
   - 刊头写着当天日期和农历干支（香港天文台农历接口）。

3. **按天气推歌的电台**
   - 根据城市、天气现象、气温、昼夜和风速推导出「声景频道」，在 iTunes 中检索华语人声歌曲，播放 30 秒试听；可以播放、暂停、切上一首或下一首、自动连播、拖动进度。
   - 电台栏可以切换「随天气 / 华语流行 / 城市民谣 / 治愈纯音 / 微醺爵士」，可以「换一批」，也可以直接**点歌**（歌名或歌手）。如果 iTunes 不可用，会改用 Deezer 检索，或者 Radio Browser 上的国内电台直播流。
   - **七日预报表**：点表中任意一天，就按那天的预报天气重新推歌，「回到实况」可以恢复。

4. **环境声（折叠项）**
   - 用 Web Audio API 实时合成雨、风、炉火、风铃四路环境声，默认按当地降水、风速和气温配比，也可以手动调节，并能和音乐叠加播放。

5. **收藏簿**
   - 点播放器上的星标收藏歌曲，同时记下收藏时的城市和天气，保存在 `localStorage` 里，刷新后不会丢失，随时可以回放。

6. **加载与异常状态**
   - 图面读数显示「观测中」，歌曲记录显示「缓冲中」；接口失败时会说明原因，并提供「重试」按钮。主气象源超时时，会自动改用 MET Norway 的数据。

## 三、使用的公共 API 说明

本项目所有数据均**实时动态获取**，未在代码中写死天气或歌单数据。所用接口全部收录于作业指定的 [GitHub Public APIs](https://github.com/public-apis/public-apis) 官方仓库，免密钥（`Auth: No`）、支持 `HTTPS` 与浏览器跨域（`CORS: *`），国内网络直连稳定快速：

| 序号 | API 名称 | Public APIs 所属分类 | 用途说明 |
| :--- | :--- | :--- | :--- |
| 1 | **Open-Meteo Weather, Geocoding & Air Quality API** | `Weather` / `Environment` | 中文城市经纬度检索、PM2.5 / AQI 空气质量指数、实时气象与多日预报 |
| 2 | **Meteorologisk Institutt (MET Norway) API** | `Weather` | 全球高精度气象实时观测与未来 7 天预报（与 Open-Meteo 构成双源毫秒级竞速容灾） |
| 3 | **Apple iTunes Search API** | `Music` | 根据气象智能映射词组实时检索华语流行与网络热歌、获取高清专辑黑胶封面与正版人声试听流 |
| 4 | **Radio Browser API** | `Music` | 实时拉取国内在线 FM 音乐广播电台列表（接入 `.cn` 纯 MP3 24 小时全长音乐实况连播） |
| 5 | **Hong Kong Observatory Open Data API** | `Weather` | 实时查询当日中国传统农历年份、生肖与农历月日 |
| 6 | **Deezer API** | `Music` | 备用人声曲库：iTunes 在当前网络不可达时自动接管（JSONP + 标准 MP3 试听流） |

> **音乐链路三级容灾**：iTunes（CORS fetch 与 JSONP 双通道竞速）→ Deezer 备用曲库 → Radio Browser 国内 FM 音乐台 MP3 直播。任何一级可用时都能出声，并在界面上提示当前使用的来源。

## 界面设计：气象站填图纸（Impeccable）

第二版视觉用 [Impeccable](https://github.com/pbakaus/impeccable) 设计技能重做，目标是**去掉“AI 模板感”**：不再使用暗色背景、霓虹光晕、玻璃卡片层层堆叠的科技仪表盘风格。

- **流程**：`PRODUCT.md` 写清用户与目标 → 生成 4 个方向的效果图并选定「气象站填图纸」→ 再为同一方向画出三种构图（填图 / 站点 / 自记）→ 按效果图写代码（效果图保存在 `.impeccable/mocks/`）。
- **视觉语言**：冷灰绿色的纸面（`#eceee9`，带细纸纹）、蓝色墨线画经纬网和等温线、黑色等宽数字；**红色（暖锋红 `#a8321e`）只用于“当前选中 / 正在播放 / 警示”**三种状态。不画陆地轮廓，只用站点和等温线表达地理关系。
- **字体**：全站只用一款衬线字 **Noto Serif SC（思源宋体，SIL OFL 1.1）**。用 `scripts/subset-fonts.py` 子集化后放在 `src/assets/fonts/`（常规体包含 GB2312 一级常用字和界面用字，粗体只含界面用字），不依赖 Google Fonts，在国内和离线时都能正常显示。
- **数据绘图**：`src/utils/chart.js` 自己实现了等经纬投影、反距离加权插值加 marching squares 的等温线、Catmull-Rom 平滑、云量八分位、风羽和 Beaufort 风级，以及防止站名互相压住的标签避让算法。
- **自检**：Impeccable 自带的反模式检测器，在改版前对页面扫出 17 项问题（光晕、渐变字、侧边色条、嵌套卡片等）；改版后源码扫描和三种图式的实际页面扫描结果**都是 0 项**。另外保持文字对比度 ≥ 4.5:1、可见的键盘焦点、`prefers-reduced-motion` 时关闭动效，移动端 390px 宽度下没有横向溢出。

> 上一版（ui-ux-pro-max 技能生成的暗色玻璃风格）的设计规范仍保留在 `design-system/` 中，可以和 Git 历史中的 Commit 10 对照。
